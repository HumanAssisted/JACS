# Native compatibility reference

The [preserved native documentation](native/index.html) covers Node, Python,
Go, email, media, storage and the native Rust APIs. Each rendered chapter is
labelled as native compatibility documentation. Its CLI examples predate the
executable rename: use `jacs-compat` for those native commands.

Use [native MCP profiles](native-mcp.md) to determine which tools are actually
available at runtime. A compiled tool inventory is not an authorization grant.
