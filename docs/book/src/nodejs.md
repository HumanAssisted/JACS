# Node.js library

```sh
npm install --save-exact @hai.ai/jacs@0.15.0
```

The package includes native bindings for the released platforms. It supports
direct application integration as well as MCP adapters. It is separate from
the browser package, `@hai.ai/jacs-wasm`.

Start with the [simple API](native/nodejs/simple-api.html),
[instance API](native/nodejs/basic-usage.html) or
[API reference](native/nodejs/api.html). Framework guides cover
[Express](native/nodejs/express.html), [Koa](native/nodejs/koa.html),
[LangChain.js](native/nodejs/langchain.html) and
[Vercel AI SDK](native/nodejs/vercel-ai.html).

The [current package README](https://github.com/HumanAssisted/JACS/blob/main/archive/native/jacsnpm/README.md)
explains CLI download behavior, public approval verification and request/event
authentication. Older reference chapters can contain pre-0.15 registry status;
the [release inventory](https://github.com/HumanAssisted/JACS/blob/main/docs/release-status.md)
records current verified artifacts.
